# YourTimeRoulette

Activity management and roulette application built with Next.js 15, TypeScript, and Tailwind CSS.

## Features

- 🎯 Activity and category management with CRUD operations
- 🎰 Weighted activity roulette selection
- 📱 Responsive design with modern UI
- 🔒 Type-safe with TypeScript
- 🎨 Beautiful interface with soft color palette
- 📊 PostgreSQL database with Prisma ORM
- ⚡ Next.js 15 with App Router and Server Actions

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Database**: PostgreSQL with Prisma
- **Deployment**: Vercel
- **Forms**: Server Actions

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up your database and environment variables
4. Run migrations: `npx prisma db push`
5. Start development server: `npm run dev`

Deployed at: https://yourtimeroulette.vercel.app
